2.2.1. Projetos Acadêmicos — Aprendizagem por Projetos Integradores (API)

Projeto Integrador (API) • 2º Semestre

Landing Page de Captação e Pré-Qualificação de Clientes

Empresa Parceira: DM (antiga DMcard)
Descrição do Problema

A necessidade de captar solicitações de crédito de forma simples e intuitiva, garantindo a validação automatizada de pré-qualificação nas bases da DM e a aplicação precisa das regras de negócio conforme o perfil do solicitante (colaborador ou cliente externo), a modalidade escolhida (Cartão DM bandeirado, Cartão Loja físico ou Cartão Loja Digital) e a disponibilidade de lojistas parceiros no estado (UF) do cliente.

Solução Desenvolvida

Aplicação web full stack conteinerizada com Docker para captação e triagem automatizada de propostas (PAC). O sistema coleta dados pessoais e CEP, identifica colaboradores DM para aplicar aprovação automática no Cartão DM ou bloqueio no Cartão Loja, filtra lojas físicas por estado, exibe avisos de emissão exclusivamente digital, permite acompanhar o status da solicitação e oferece painel administrativo para cadastro de novos lojistas parceiros e oferta de produtos alternativos (EP e DMCred) em casos de reprovação.

Contribuições Pessoais
  • Desenvolvimento da lógica de back-end em Python e implementação das regras de negócio de pré-qualificação e filtragem por CEP/UF.
  • Modelagem e integração com banco de dados relacional MySQL para persistência de clientes, lojistas parceiros e propostas (PAC).
Tecnologias Utilizadas
  • Python
  • MySQL
  • HTML5
  • CSS3
  • JavaScript
  • Docker & Docker Compose
  • Git & GitHub
Hard Skills Adquiridas
  • Implementação de regras de negócio condicionais e validação de dados cadastrais/geográficos no back-end.
  • Integração entre aplicação Python, banco de dados relacional MySQL e front-end web.
  • Padronização de ambiente de desenvolvimento multi-serviço com Docker Compose.
Soft Skills Exercitadas
  • Trabalho em equipe ágil (Scrum) com definição de DoR, DoD e entregas incrementais por Sprints.
  • Comunicação técnica para traduzir requisitos complexos de negócio da empresa parceira em critérios de aceite.
  • Organização documental e revisão colaborativa de código via Pull Requests.

Projeto Integrador (API)

Projeto Oswaldo — Assistente Informativo de Vacinação

Parceiro do Projeto: Parceiro interno FATEC
Descrição do Problema

A dispersão de informações públicas sobre campanhas, calendários e critérios de vacinação no Brasil dificulta o acesso rápido e claro por parte da população, exigindo a consulta manual a múltiplos portais governamentais pouco intuitivos para esclarecer dúvidas cotidianas.

Solução Desenvolvida

Desenvolvimento de um bot conversacional no Telegram capaz de coletar dados atualizados de fontes oficiais via web scraping e processar perguntas em linguagem natural utilizando um modelo de linguagem (LLM) executado localmente via Ollama, entregando respostas diretas e contextualizadas ao usuário.

Contribuições Pessoais
  • Implementação das rotinas de extração e estruturação de dados públicos em Python.
  • Integração do fluxo conversacional com a API do Telegram e inferência local via Ollama.
  • Versionamento colaborativo, revisão de código e organização dos artefatos da equipe no GitHub.
Tecnologias Utilizadas
  • Python
  • Web Scraping
  • Telegram Bot API
  • Ollama (LLMs Locais)
  • Git & GitHub
Hard Skills Adquiridas
  • Extração automatizada de dados (web scraping) e tratamento de exceções.
  • Integração de APIs assíncronas e orquestração de modelos locais de IA.
  • Controle de versão em equipe com fluxo de branches e pull requests.
Soft Skills Exercitadas
  • Comunicação técnica e alinhamento contínuo com os integrantes do time.
  • Elicitação e tradução de requisitos do parceiro em entregas incrementais.
  • Gestão de tempo e resolução colaborativa de gargalos técnicos sob prazo.
